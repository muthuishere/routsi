Install

routsi ships as a single binary. Three ways to get it — pick one.

npm (recommended)

The npm package's postinstall downloads the right prebuilt binary for your OS/arch from GitHub Releases — no Go toolchain, no building from source.

install globally
npm install -g @muthuishere/routsi
routsi version

Prebuilt release binary

Grab the archive for your platform from the releases page, unpack, and put routsi on your PATH.

From source

Go 1.22+ · Taskfile v3
git clone https://github.com/muthuishere/routsi && cd routsi
task build          # → bin/routsi (version-stamped)
task install        # → ~/.local/bin/routsi
