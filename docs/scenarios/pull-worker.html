6 · Pull-worker

A remote agent registers a queue; requests to that queue name route to it.

on the worker machine
routsi worker run --proxy https://your-proxy:8080 --queue my-agent \
  --agent 'codex exec -'
from any client
curl localhost:8080/v1/chat/completions \
  -d '{"model":"my-agent","messages":[{"role":"user","content":"hi"}]}'
# → routed to the registered worker; 503 fast if none is polling

Full config reference: Pull-workers.
